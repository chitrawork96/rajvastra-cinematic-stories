# Rajvastra: Heritage Bandhani Brand

**Volunteer project · Landing page prototype**

Rajvastra is a small Jaipur heritage Bandhani brand working with 120+ artisans, with no prior digital presence. As a volunteer project, I worked on its brand positioning and built this landing page prototype to present the craft to modern online buyers. This is a prototype, not the brand's official site.

🔗 **Prototype:** [rajvastra-cinematic-stories.lovable.app](https://rajvastra-cinematic-stories.lovable.app)

## What I did
- Brand positioning and story: "Rooted in Rajasthan. Woven for Today."
- Brand narrative and storytelling
- Landing page architecture, copy and conversion design
- An Instagram and newsletter acquisition framework
- A cinematic landing page prototype built with Lovable

## Built with
Lovable · TypeScript · ChatGPT · Claude
